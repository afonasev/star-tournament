# Плавные first-person шаги

Итог: 23 EditMode и 9 различных PlayMode проверок прошли. Проверены настоящие rig/clips, мягкий ритм, переход к покою, отсутствие накопления при повторном кадре/паузе, воздух, respawn, fire/hit/switch и независимость viewport. Исторические hashes и custom values сохранены; новые поля доступны после upgrade сериализованного профиля.

`playmode-neighbors.xml` содержит восемь действующих соседних проверок. Его девятый case покачивания заменён исправленным сценарием в `playmode-motion.xml`: Restore на каждом кадре сбрасывал анимацию и делал исходный upper-bound сценарий слабым. Исправленный сценарий использует игровые movement ticks, settled capsules, открытый проход и требует ненулевого покачивания; ни один bound/контракт не ослаблен.

`motion.csv` содержит 264 измерения настоящего weapon mount в camera-local координатах для четырёх оружий. Максимальное смещение за 20 ms — 0.0012291 m; боковая амплитуда достигла 0.007913 m при default 0.008 m. Это техническая плавность с выбранным шагом наблюдения, а не человеческая оценка ощущения шагов.

Кадры `Rifle.png`, `Shotgun.png`, `RocketLauncher.png`, `Cutter.png` просмотрены: хват сохранён, геометрия читается, центр viewport открыт. Справа — неподвижный второй участник. HUD не входит в прямой camera RenderTexture этого fixture.

Первый graphics запуск остановлен после выявленной ошибки startup cache; `startup-error-fixed.txt` сохраняет её первичное сообщение. Исправление: обновление valueIndex после добавления descriptors/values. Два последующих диагностических motion setups выявили физическую коррекцию после placement и стену на маршруте; исправлены только начальные условия. Полная история выбора проверок — `qa-scope.md`; итоги и source SHA256 — `results.json`.

XML duration включает setup/teardown и загрузку сцены, не только test body. Full suite, Player/release build, поставка и субъективная/физическая приёмка не выполнялись. Проверяемый источник сохранён в Git задачи; точный commit записан в shared delivery/acceptance guide.
