# Проверка результата source integration

Точный source commit и проверенная интеграция будут записаны в verification.json. Реализация переносит отсутствующие функции из codex/game-standard-alignment, сохраняет новый Well и учитывает актуальный released updater. См. README.md и reconciliation.json.

Для человеческой приёмки при отдельном запуске: открыть Lab со своей историей, проверить список старых версий, типизированные значения, dirty-warning и явный выбор Default при ошибке авторской истории; в настройках выбрать качество; в локальной паузе проверить профиль/версию баланса каждого viewport; проверить реальные gamepad-family hints/Back и Well garden/daylight. Пользовательские сохранённые значения, исходные revisions/hash/date и factory Default имеют разные роли.

Нативные Windows UAC/ACL/installer recovery и автоматический переход установленной версии, Finder/Applications/Gatekeeper, physical devices/TV, аудио и человеческая gameplay-приёмка не доказаны переносимыми fixtures. Новая сборка/установка/публикация здесь не выполняются. Source QA не закрывает старые native gates children.
