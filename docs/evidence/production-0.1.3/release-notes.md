Star Tournament 0.1.3 — 10.10.2026.

В релиз вошли все закоммиченные изменения main 97c42610: новые экраны загрузки запуска и матча, ускоренная обработка и staging истории Lab, обновлённые подсказки меню и курсор при управлении геймпадом, настройки прицеливания, улучшенное поведение ботов, компактные результаты, направленная реакция на попадания и эффекты отдельных дробин, более тихая музыка относительно эффектов и плавное движение рук при ходьбе.

Windows-загрузчик теперь явно объявляет PerMonitorV2 DPI awareness; упаковка проверяет manifest реального EXE. Unity Player запускается отдельным процессом и содержит собственный PerMonitorV2 manifest. Фактическое разрешение/полноэкранный режим при Windows scaling 300% требуют проверки на Windows.

Windows x64 и macOS arm64 имеют общую версию 0.1.3, парные установщики и подписанные обновления production. Test-установки сохраняют свой канал. Сохранён контракт Program Files/UAC, исходная Lab-история не сбрасывается.

Адресные автоматические проверки и native macOS startup smoke записаны в release evidence. Полный прогон всех тестов этой выкаткой не запрашивался. OS developer signing/notarization и физическая проверка установки/контроллеров остаются отдельной приёмкой.
