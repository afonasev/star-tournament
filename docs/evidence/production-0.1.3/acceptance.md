# Проверка production 0.1.3

Точный runtime source: `97c42610`; public source: `fd17c8e5c1fc018a88dbfa6282f6e5b492f2700f`.
Релиз: https://github.com/afonasev/star-tournament/releases/tag/v0.1.3.

1. Установить нужный production 0.1.3 installer или обновить существующую production-установку через её обычный интерфейс. Test-канал не меняется автоматически.
2. На Windows при масштабе 300% проверить запуск, выбор поддерживаемого разрешения, полноэкранный/оконный режим и сохранение настроек. Проверить фактический размер и читаемость на экране; embedded DPI manifest сам по себе не доказывает эту приёмку.
3. Проверить отзывчивый экран загрузки, готовность основного меню, переходы настройки/матча/паузы/результатов, сохранность старой Lab-истории.
4. Проверить геймпад и мышь: курсор, навигацию и прицеливание; в матче — реакцию на попадание, эффекты щита/дробовика, движение рук и музыкальный баланс.

Автоматические tests/build/native smoke/public readbacks не являются физической или сенсорной приёмкой. Установленная на локальной машине игра этим процессом не обновляется. Исторические релизы и retained кандидаты сохраняются.
