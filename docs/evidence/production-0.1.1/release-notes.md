Star Tournament 0.1.1 — 09.10.2026.

- Достижения: видимая причина выдачи, контурные медали, небольшой штамп «Заслужено»; 1–3 карточки центрируются.
- Пересмотрены восемь условий наград: они допускают попадания и убийства в обычной игре. За бездействие награды не выдаются. Старые сохранённые награды сохраняют прежние правила и описания.
- Компактные результаты и TAB: уменьшена шапка, у ботов только иконка и сложность.
- Личный счёт против соперников: шлемы VS, белый при равенстве, зелёный при преимуществе, красный при проигрыше. В результатах можно выбрать участника и посмотреть его противостояния.

Windows x64: установщик в Program Files с UAC. macOS: Apple Silicon arm64 PKG. Подписанные обновления доступны в production-канале; загрузка и перезапуск требуют согласия игрока. Тестовые установки сохраняют test-канал; переход в production — через production-установщик.

OS developer signing/notarization не предоставляются. Автоматические проверки не заменяют физическую приёмку Windows/macOS/контроллеров. Частота новых наград в живых матчах пока не измерялась.
