# VECTOR F11 — форма и ткани FPS

Выбранное направление: форма `../f11-fps-concepts/concept-3.png`, плетение и швы `concept-2.png`. Это художественные макеты; игровые камера/FOV и масштаб оружия сохранены.

Редактируемый исходник: `scripts/vector_fighter/f11-fps-forms.blend`.
Воспроизводимый экспорт: `scripts/vector_fighter/refine_fps_forms.py`, исходная база F9 сохранена.

Изменены округлый контур керамики, переход рукава в компактную манжету, посадка существующих элементов перчатки и woven PBR-карты. Новые накладки не добавлены. Семь анимаций, иерархия костей, походка F7, оружие, motor/physics и камера сохранены.

Trooper @17: параметр `grip.<weapon>.wristAlignment` переносит локоть при фиксированном хвате. В игре измерено: RocketLauncher 39.73° → 20.63°, Cutter 48.20° → 24.17°. Rifle 8.47° и Shotgun 11.27° не меняются. Проверка подтверждает неизменность позиций/ориентаций ладони и всех фаланг, mount и длин костей. Старый @16 и цепочка прежних factory snapshots сохранены.

Полная художественная приёмка VECTOR остаётся открытой. Full suite, Player build, интеграция, release/deploy и физическая/производительная приёмка в этот срез не входят. Все continuation-ресурсы сохранены по прямому запросу пользователя.
