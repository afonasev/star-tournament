# F15 — анатомия перчаток при фиксированном положении рук

Baseline: `codex/vector-fighter` / `128ab5628be893312b203891fc406c66bc506056`. F14 художественно отклонён пользователем. Scope: обе кисти, все пальцы и четыре хвата; плечи, предплечья, кистевые кости, оружие и камера остаются на прежних местах. Согласованное уменьшение бокового выступа Shotgun сохранено.

## Изменения

- Основание большого пальца построено как расширяющийся объём ладони с переходом к двум открытым фалангам. Прежний длинный узкий метакарпальный объём заменён, распределение весов ограничено областью большого пальца.
- Край ладони следует индивидуальному ряду пястно-фаланговых суставов. Поперечные сечения ладони уплощены и закруглены; переход к круглой манжете сохранён.
- Длинные соединительные капсулы остальных пальцев удалены. Корни фаланг входят в ладонь через короткие округлые объёмы костяшек; устранены выступающие метакарпальные окончания.
- Жёсткие ладонные накладки следуют кисти, отдельные щитки — своим фалангам. Они больше не растягиваются между соседними пальцами.
- Профиль factory20, сохранённые Lab-профили, runtime-решатель и значения суставов не изменены. Иерархия костей, все семь анимаций и геометрия утверждённого Shotgun точны относительно F14.

Авторский исходник: `scripts/vector_fighter/f15-hand-anatomy.blend`; генератор: `scripts/vector_fighter/refine_finger_phalanges.py`. F11/F14 и остальные исходники сохранены. Итоговый экспорт: `.local/vector-f15/export8.log`, SHA256 — `qa/glb-verification.json`.

## Просмотр

Откройте `review.html`: настоящий Unity FPS каждого оружия, обе руки с трёх сторон, затем стрельба/подъём/падение/приземление. `native/` содержит оригинальные PNG и CSV; контактные листы только размещают/масштабируют исходные изображения, без ретуши. `neutral/` — диагностические Blender-рендеры экспортированной GLB, деформированной сохранёнными Unity-костями и inverse-bind matrices. Они раскрывают форму ткани, но не заменяют Unity-кадры.

Осмотр включает большой, указательный, средний, безымянный и мизинец каждой руки: основание/перепонки, суставы, цельность поверхности, пропорции видимых фаланг и контакт с оружием. Положение каждого пальца в четырёх фазах сверяется отдельно через `qa/pose-audit.json`. Это самопроверка кандидата, не художественная приёмка человека и не сертификат точного отсутствия пересечений всех треугольников.

## Проверки и сохранённые неудачи

Финальный PlayMode **6/6 PASS**, импорт EditMode **3/3 PASS**: `qa/verification.json`, исходные XML рядом. Сравнение костей дало нулевое изменение положения плеч/предплечий/кистей относительно F14; во всех фазах максимальная разница пальцев относительно кисти — 0.00000699 единицы / 0.00150°, в пределах точности текстовой выгрузки. См. `review-matrix.md`. Фильтры/обоснование — `qa/scope.md`.

Первый вариант сценария фаз не выдал Shotgun патроны: 3/4 PASS, capture FAIL. Второй общий capture четырёх оружий превысил штатные 180 секунд: 3/4 PASS, capture timeout. Оба XML сохранены. Исправлены setup боезапаса и разделение на отдельный случай для каждого оружия; прежние тестовые assertions, длительности, seeds и timeout не ослаблены.

Отвергнутые диагностические варианты 1–7 сохранены в `.local/vector-f15/`. Первый вариант имел чрезмерное влияние большого пальца на соседние поверхности; последующие выявили лишнюю перепонку, чрезмерный объём и длинные переходы у мизинца. Ошибка имени в черновом генераторе и отдельные voxel-фрагменты не скрыты в логах. Итоговый экспорт дал ровно две связанные поверхности без удаления фрагментов; строгая проверка двух компонентов сохранена.

Full suite, Player, физические устройства, performance, merge, release и deploy не выполнялись. Все `.local/vector-*`, Library, исходники и исходный `__pycache__` сохраняются по прямому поручению. Более широкая доработка костюма F5 и человеческая художественная приёмка остаются открытыми.
