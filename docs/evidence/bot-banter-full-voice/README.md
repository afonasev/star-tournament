# Полная озвучка ботов

20 существующих фраз, один мужской голос `ru-RU-DmitryNeural`, более низкий тон и резкий темп относительно пробника. Радио: полоса130–3500Hz, усиление середины/разборчивости, быстрая компрессия, мягкий перегруз и тихий шум. Несколько насмешек начинаются с короткого «Хех». Новые реплики/условия/частота не вводятся.

`manifest.json` — точный текст, ключ и произносимая строка. `source/` — исходные записи. `generation.json` — pinned provider/rate/pitch/filter, decoded measurements и hashes. `all-phrases.mp3` — все 20 в порядке manifest с паузами; `preview.mp3` — три разных примера. Runtime audio assets находятся в Resources/Audio/Banter, точный C# каталог — NativeBotBanterVoice.

Повторная обработка: `uv run --with edge-tts==7.2.8 python tools/audio/generate_bot_banter.py`. При наличии исходников синтез пропускается; network нужен только для отсутствующих raw источников. Смена prosody требует явно обновить соответствующие raw источники. Параметры нормализации: target-18LUFS, ceiling-3dBTP; фактические значения учитывают кодирование/ограничение коротких фраз. Import normalizeOFF, mono48k, nonspatial one-shot.

Все 20 текстов имеют собственные записи. VoiceOFF немедленно останавливает только bot source. Effects/mute/pause/results/restore/rebind/dispose без повторного запуска. SpeakerMayBeDead разрешает жалобы/конец серии/самоиронию погибшего; живое хвастовство погибшего отклоняется/останавливается. Общая редкость/история/text/voice preferences прежние.

Команды/основания проверки — scope.md; XML, source hashes и результаты сохранены здесь. Автоматические import/playback/mix/ASR измерения не подтверждают эмоциональную подачу и слышимость в реальном бою. Human listening/gameplay acceptance pending. Player/build/release/deploy не выполнялись.

Первую обработку пересмотрели после ASR диагностики: чрезмерное pitch lowering и drive ухудшали распознавание против raw. Финальная версия сохраняет низкий TTS pitch, но снижает дополнительное понижение до ratio0.94, перегруз и расширяет полосу. Исходные/первые/candidate/final транскрипции — asr-comparison.json; ASR ошибается на коротких русских фразах и «Хех», поэтому его результат диагностический. Длиннейшая запись ~4.85s может закончиться чуть позже четырёхсекундного текста; она не повторяется на respawn.
