# Проверка production 0.1.4

Релиз: https://github.com/afonasev/star-tournament/releases/tag/v0.1.4.
Точный runtime source: `358fab9a5e6ebd3aea4aee57e68c8666346aa56c`; public source/tag: `13f082a6a923b1e3006e7465405261d14d0b1967`.

1. Установить нужный installer 0.1.4 или обновить production-установку через её интерфейс. Публикация сама не обновляет установленную игру; test-канал отдельный.
2. Проверить запуск меню со старой Lab-историей, матч, паузу и результаты. На Windows проверить размер интерфейса при масштабе 300%, поддерживаемые разрешения и оконный/полноэкранный режим; на macOS — обычный запуск после установки.
3. В настройках проверить четыре комбинации «Реакции ботов: текст» и «Реакции ботов: голос» и их сохранение. В матче оценить редкость/уместность реплик, ускоренную речь, грубый голос/рацию и слышимость на фоне боя. У погибшего бота жалоба допустима; живая реплика прекращается при его смерти.
4. Проверить серии убийств, очки и голосовые сигналы третьего/четвёртого убийства, геймпад/мышь, сигнал готовности оружия и баланс музыки/эффектов.

Автоматические tests/build/native smoke/public readbacks не заменяют физическую и звуковую приёмку. Предыдущее «принято» относится к ускоренной исходной озвучке; приёмка опубликованного Player отдельно остаётся открытой.
