# Естественные условия шуточных достижений

Восемь условий заменены сравнительными рекордами. Зачем тебе патроны? больше не требует ни одного попадания за весь матч; остальные золотые не требуют нулевых убийств или преобладания self/ally harm над enemy combat. Почти опасный доступно единственному участнику с минимумом убийств, включая дуэль; полная ничья нескольких участников группы не даёт рекорд. Для v2 требуется урон врагу или существующий порог стрельбы. Названия, металлы, RNG и один получатель/награда сохранены.

RulesVersion 2 записывается в новые награды; отсутствующая версия означает v1. Legacy frozen награды проверяются по прежним условиям, фактам и показывают прежние объяснения. Неизвестная версия и подделка фактов отвергаются до мутации.

Проверки: каталог 41/41; остальные core/telemetry/history/scoreboard 15/15 (core.xml содержит 55 до добавления shared-gold test, catalog.xml — финальные 41). PlayMode 6/6: реальные сессионные counters, описание всех 30, все 30 layout на 960x540–4K и native results renders. UI 16/16. PNG используют synthetic frozen fixture, не являются записью естественного матча. Controlled Player review обновлён для нового gate, но standalone не запускался.

Условия допускают ненулевые убийства/попадания и небольшие случайные self/ally ошибки; частота выпадения в живых матчах не измерялась. Player build, device acceptance, release/deploy отдельно, не запускались.
