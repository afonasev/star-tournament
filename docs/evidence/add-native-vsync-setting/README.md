# VSync в native настройках
Проверенный source `751afc33`, baseline `2e56d237`. Общий checkbox «Вертикальная синхронизация (VSync)» в меню/личной паузе; значения сохраняются. On: каждый refresh (`vSyncCount=1`); off: `0`. Без допустимого preference исходная настройка качества сохраняется, включая count=2. При teardown исходное состояние восстанавливается, Application.targetFrameRate не меняется.
PlayMode 5/5 passed, failed/skipped 0. Один shared GPU Editor run, muted, isolated Lab history. Проверены preference default/invalid/on/off/reload/restore, API limiter invariance, две паузы с frozen clock, реальный автоматизированный gamepad submit/focus и нижняя часть graphics scroll. Четыре Editor PNG просмотрены; XML и gzip log сохранены. Source-only, не physical screen или Player acceptance.
`qa-scope.md` содержит выбор affected проверок. Player/build/full/release/deploy не запускались. Реальное tearing/frame pacing/monitor и human acceptance открыты; FPS не измерялся.
Документация Unity 6000.3: https://docs.unity3d.com/6000.3/Documentation/ScriptReference/QualitySettings-vSyncCount.html . На desktop при vSyncCount>0 targetFrameRate игнорируется; код сохраняет его значение, чтобы off не менял существующий limiter.
