# Итоговая таблица и выравнивание взгляда

Три исправления по прямому поручению пользователя в сессии `01a121b4-1141-7a21-852f-ae3eecb89bf8`.

- Итоговая таблица, награды и действия используют общий центральный frame: масштаб обеих осей одинаковый, внешние отступы не меньше 6% по каждой оси. Геометрия проверена на 1280×720, 1920×1080, 3440×1440 и 3840×2160, в FFA и командном режиме.
- В «Управление» добавлена личная/общая задержка автовыравнивания, 0–3 с с шагом 0,05 с. Default берётся из существующего movement descriptor. Identities сохраняют значение между запусками, guests — в своём session lifetime; старые identities используют профильную задержку.
- Короткий LT плавно возвращает authoritative pitch к мировому горизонту; default 0,18 с находится в Balance Lab `unity-proving-ground-v1@15`. Ручной ввод, pause/input clear, focus loss, смерть и disconnect отменяют возврат. Yaw, длинное удержание LT и RT сохраняют свои контракты; камера и выстрел используют одинаковую текущую ориентацию.
- Для схем @13 и @14 сначала проверяются точные доверенные проекции shipped registry. Это исключает перебор более старых схем при их точном совпадении; проверки hash, ranges и metadata сохранены.

## Проверки

- `editmode.xml`: 79/79 — полные GamepadLookSettings, SeatInput, GamepadCompatibility, DesignLabHistory и LabReleaseCatalog fixtures до последних прямых путей миграции.
- `input-editmode.xml`: 21/21 — повтор input/settings и миграция @14 после первой оптимизации.
- `migration-editmode.xml`: 2/2 — финальные миграции @13/@14 с сохранением личной задержки и исторического hash.
- `ui-editmode.xml`, `ui-playmode.xml`, `ui-result.json`: `make check-ui`, 3 EditMode + 13 PlayMode.
- `affected-playmode-initial.xml`: 27 из 28 прошли. Старый synthetic Tab сценарий проверял видимость до Dynamic Update, который обрабатывает очередь устройства. В fixture добавлено ожидание Dynamic Update перед fixed tick; проверки видимости, владельцев, значений и отпускания оставлены.
- `rivalry-playmode.xml`: финальный полный повтор NativeRivalryInputTests после исправления порядка ожидания.
- `render-playmode.xml`: 2/2 — рендеры итоговых результатов, сохранённая immutable статистика, выбор строк/действий и новый слайдер настроек.
- PNG осмотрены: Full HD командный результат, ultrawide FFA, 4K FFA, управление. Полные изображения сохранены рядом с этим отчётом.
- `git diff --check`; строгая OpenSpec validation change и всех 64 canonical specs.

Два незавершённых прогона на версиях кода до исправления путей миграции были остановлены через принадлежащие задаче guardians (exit 143, без итогового XML). Они не являются assertion failures или успешной проверкой. Сохранённые XML выше относятся к завершённым прогонам.

QA не собирала Player, release или установщик и не выполняла публикацию. PNG — рендеры Editor PlayMode, автоматический input — synthetic gamepads. Физический контроллер и human acceptance результата остаются открытыми; build/Player/release/deploy ждут отдельной команды пользователя.
