# Отложенная проверка человеком

Предварительное согласование03 — разрешение реализации, не приёмка Player. После отдельной команды на сборку проверить установленную совместимую пару launcher/Player:

1. Одно обращение discovery при запуске; в меню и после ошибки ручной повтор отсутствует. Проверить офлайн/медленную сеть и сохранение установленной версии/даты.
2. «Обновить» показывает именно выбранную версию, процент и полосу; фокус остаётся у игрока. «Отменить» прекращает операцию; выход не ожидает полный файл.
3. Начать матч при metadata и package transfer: трафик должен полностью прекратиться до Running. В меню продолжается только согласованная загрузка той же версии; отменённая загрузка не оживает.
4. Приготовленный пакет объясняет установку после выхода; играть можно дальше. «Перезапустить» проходит защиту черновика Lab; running identity меняется только после установки.
5. Разрыв IPC/ошибка доступа/таймаут ack не допускает матч; показано понятное сообщение с возвратом подготовки. Проверить Windows/macOS, UAC и физический геймпад отдельно.

История04 и startup-health rollback ещё не реализованы этим срезом; весь updater не считать принятым. Нельзя архивировать инициативу по одному этому guide.
