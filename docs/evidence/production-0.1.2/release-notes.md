Исправлена иконка Windows-установщика и удаления: Modern UI теперь использует утверждённую иконку игры вместо стандартной NSIS.

OS developer signing/notarization не предоставляются; вид Explorer/мастера установки на реальном Windows требует отдельной проверки.
