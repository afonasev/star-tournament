# Проверка нового оформления меню

Изменение: `restyle-native-menu-suite`. Выбранный пользователем вариант 1 «Арена / эфир», фон орбитальной арены; декоративные верхние и правые подписи главного меню удалены.

## Охват

- Главное меню и состояния кнопок.
- Карта, правила, состав матча, редактор человека/бота, выбор профиля и сложности.
- Профили игроков и личные настройки.
- Изображение, разрешения/подтверждение/откат, управление, справка клавиатуры и геймпада, устройства, интерфейс и звук.
- Лаборатория, создание/переименование/удаление, изменения, ошибки, история, поиск и подтверждения.
- Личная пауза на одном и четырёх экранах, личные настройки и подтверждения; общая операторская пауза; результаты.

## Границы доказательств

UI-only gate и дополнительные тесты подтверждают затронутые UI контракты. Синтетический native Player использует изолированные профили и Lab history; изображения подписаны по реальному состоянию. Это не физическая проверка контроллеров, не Windows smoke, не human acceptance и не полный gameplay/AI gate. Цветовые идентичности участников и gameplay HUD не перерабатывались.

## Приёмка

Проверить визуальную плотность и читаемость меню на целевом экране, длинные русские подписи, мышь и физический геймпад, прокрутку Lab, личную паузу каждого игрока и возврат назад. Все прежние действия должны оставаться доступны. Сеть остаётся недоступной. Не менять настоящие профили ради QA; использовать новый временный профиль по желанию.
