Результат ожидает человеческой оценки. Предыдущий проход main@973c2877 не принят: пользователь счёл детализацию и сходство с концептом недостаточными.

## Сравнение
Ориентир: [согласованный концепт](../well-lab-detail/approved-concept.png). Baseline: [предыдущий атриум](../well-lab-richness/views/atrium-corner.png).

Финальные кадры находятся в [views](views/): 23 исходных ракурса, native 1920×1080. Это реальные Editor render captures, без дорисовки. Старые кадры имели 1280×720. Настройки захвата записаны в views/render-state.txt.

Проверить:
1. atrium-corner и physics-gallery: тени мостов, контакт перекрытий/стен, многослойные оконные профили, светлый металл, чистая надпись КОЛОДЕЦ.
2. corner-room / stair-room / electronics-room: контакт пола/стен, фаски дверных рам, фактура технического пола. Ширина и высота проходов физически прежние.
3. department-module-0/1/2: объёмные кассеты, дисплеи с графиками и ручками, платы с контактами/разъёмами. Русская маркировка выше оборудования, без наложения.
4. Оба лифта на трёх этажах: сохранены видимость площадки/входа и закрытые стыки стен. Это обзор оформления; механика лифтов отдельно здесь не переигрывалась.
5. garden-detail: грунт и прежние клумбы сохранены. Растения не заменены новой генеративной геометрией.

## Что изменилось
Дневной свет и визуальная fixture используют единый Well contract. Стекло больше не получает roughness/metallic стены. Reflection capture расположен в атриуме. Для пола/стен добавлена статическая contact visibility по authored bounds; она влияет на indirect light, не на коллизии. Появились реальные фаски профилей, цилиндрические детали, приборный atlas и геометрия печатных плат. Well Lab v3 содержит новые регуляторы и сохраняет exact v2/v1 history.

## Границы результата
Проход технически проверяется по целевому набору. Он не означает human acceptance и не обещает точного фотореалистического совпадения с AI paintover: существующий Gamma/URP pipeline, одно окружение отражений, масштаб и угловатая авторитетная архитектура сохраняются. Свет и приборы остаются стилизованными; сходство и достаточность детализации оценивает пользователь по текущим кадрам.

Full, Player build, release, deploy не выполнялись. Editor достаточен для этих сравнений. Device/performance/FPS, игровая и человеческая приёмка не закрыты. Число lights/renderers/vertices — только ресурсный учёт.

## Воспроизведение без звука
Из checkout точного source commit запустить:
```
UNITY_RUN_MODE=shared STAR_TOURNAMENT_QA_LAB_HISTORY="$PWD/.local/well-qa-history.json" unity/tools.sh editor -batchmode -noaudio -muted -runTests -testPlatform PlayMode -testFilter WellLabDetailVisualTests -testResults "$PWD/.local/well-visual.xml" -logFile "$PWD/.local/well-visual.log"
```
Путь фактически идёт через unity-run shared. Системная громкость и чужие приложения не меняются. Установленный старый Player не содержит этот проход.

Техническая справка: [Unity: reflections](https://docs.unity.com/en-us/engine/6000.3/manual/lighting-overview/reflections/advanced-ref-probe). Настройка reflection capture не заменяет физическую геометрию или реальные прямые источники света.
