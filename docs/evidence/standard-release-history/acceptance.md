# Отложенная человеческая приёмка04

После отдельно заказанной сборки совместимой пары launcher/Player:
1. Открыть «Что нового» с доступным update и без нового update; действие всегда есть. Проверить список10+установленная, номер/дату, свой канал и отсутствие draft.
2. Проверить постоянную золотую рамку/полосу/метку установленной версии без фокуса и при подготовленном новом пакете. В коротком окне и при resize даты не обрезаются, фокус автоматически виден. Выбрать каждую версию геймпадом/мышью, прокрутить длинное описание правым стиком/колесом/PgUp/PgDn. Back возвращает фокус «Что нового»; completion не меняет выбор игрока.
3. У релиза без русского раздела видна честная надпись. У старой установленной версии описание не заменяется заметками другого релиза.
4. Offline/GitHub rate limit: сохранённая история явно обозначена либо понятная ошибка, никаких выдуманных релизов. Кеш не требует прав в Program Files.
5. Начать матч при HTTP history: download заканчивает drain до Running; запросы истории в матче отсутствуют. Выбранный пакет update и согласие не меняются.

Предварительное одобрение макета04 не является Player/device приёмкой. Новые Git-derived RU/EN descriptions будут подготовлены отдельным этапом до будущей явно заказанной публикации. Никакая публикация этим guide не разрешена.
