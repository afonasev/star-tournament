# Crystal Runes pickup asset evidence — 2026-09-23

The three GLBs are original geometry generated by `unity/Assets/StarTournament/Art/generate-crystal-rune-pickups.py` with Blender 5.2.1. `render-crystal-rune-pickups.py` renders the front, quarter, back, side, distant and eight 45-degree turntable PNGs here. `audit-crystal-rune-pickups.py` writes `asset-audit.json` with bounds, topology, materials, paired face nodes, normals and collider-node check. They have semantic mesh names, geometry on both faces, +Y up, +Z front, a ground-center pivot, and no authored colliders. Unity EditMode checks import, orientation, slim side depth, front/rear nodes and collider absence.

The first model pass was too thick and massive per user feedback. The current source uses `SILHOUETTE_SCALE = 0.82` and `DEPTH_SCALE = 0.40` relative to that first pass. These are authored mesh dimensions, not runtime balance changes.
