# Пробная озвучка бота
Запрос10.10.2026: одна аудиофраза для оценки звучания, без подключения к игре.

Текст: «Даже не поцарапал!» Голос: ru-RU-DmitryNeural, rate-10%, pitch-5Hz. Генерация через [edge-tts](https://github.com/rany2/edge-tts), онлайн-сервис Microsoft Edge. Исходный результат сохранён без эффектов/изменения громкости. Длительность2.664s,24kHz mono MP3; декодирование ffmpeg прошло, peak-5.5dBFS. Это техническая проверка файла, не оценка актёрской подачи.

Творческая цель: уверенный взрослый соперник, с лёгкой усмешкой. Первый обычный TTS-пробник позволяет оценить тембр/темп; актёрское выражение остаётся на слух пользователя. Human audition pending. Unity/сборка/выкатка не запускались, runtime audio не изменён.

Параметры и checksum: generation.json. Существующий текстовый bot-banter сохраняется без изменения. Фраза по-прежнему допустима только при реальной стрельбе человека и нулевом ответном уроне, включая щит.
