# Read-only review — Astra / medium

Предварительный вывод по первому uncapped-прогону: наиболее поддержана стоимость локального освещения в зале, особенно высоких источников. Точное падение FPS вдвое и конкретный GPU-проход пока не установлены.

- Среднее: 199–223 FPS в зале против 280–284 во дворе, то есть 21–29%, а не 50%. Медиана скрывает регулярные длинные кадры.
- Отключение локальных или высоких источников и половинный renderScale убирают длинный хвост; отключение теней его сохраняет. Это свидетельствует в пользу затрат обработки пикселей/освещения.
- `no-upper-lights` выключает все недирекционные источники выше уровня второго этажа, включая высокие лампы боковых лестниц. Называть его изоляцией только ламп верхних комнат нельзя.
- CPU-бенчмарк содержит редкие дорогие AI-тиков, но они не объясняют различие замороженных сцен.

Ограничения: GPU coverage первых замеров зала почти нулевая; GPU p50 12ms в последнем baseline при среднем frame 5ms требует осторожности и не является надёжным абсолютным бюджетом GPU. Старый CSV может повторять последний timing; JSON-distributions проверяют уникальность timestamp. В диагностике v2 CSV записывает timestamp/fresh, пустые значения для отсутствующих данных, mean, refresh rate и штатный VSync по умолчанию. Повтор с VSync обязателен. Независимый Metal trace на этом host сейчас недоступен: установлен только CommandLineTools, `xcrun xctrace list templates` не находит utility.

Кандидат для отдельной согласованной оптимизации: ограничить влияние верхних источников своим этажом, сохранив офисную яркость F6. Потребуется разделять источники и поверхности этажей; объединение мешей по материалу усложняет такую фильтрацию. Не гарантируется стоимость цикла света: нужны измерения до/после. Уменьшение пересечения диапазонов с компенсацией яркости или запекание постоянного освещения — альтернативы, требующие визуальной приёмки и, для запекания, изменения pipeline.

В текущем scope не реализовать простое отключение ламп, уменьшение качества/разрешения или смену материалов. При следующем исправлении сравнить зал, верх, лестницы, дверные проёмы на одном точном Player; сохранение яркости требует отдельной человеческой приёмки.

## Final v2 review — Astra / medium

Высокоразрешённая серия на том же бинарнике воспроизвела двор120/зал61 FPS. Локальное освещение при высоком разрешении выводит рендер за бюджет 120 Гц; штатный VSync сопровождается переходом примерно к60 FPS. Точный GPU-проход не доказан; редкие high-resolution GPU значения не использовать как бюджет. PresentWait сам по себе не измеряет полезную работу GPU.

Без теней62, без высоких локальных источников94, без локального света120, половина renderScale120 FPS. CPU main/render и геометрии в зале меньше; frozen simulation исключает ботов как причину этого воспроизведения.

Рекомендуется отдельный согласованный визуальный прототип уменьшения перекрытия локальных источников обоих этажей, начиная с раздельного измерения point-fill/spot групп. Сохранить яркость/характерF6. Отключение только верхних ламп недостаточно. Если это не удастся — отдельно рассмотреть baked static lighting плюс освещение персонажей. Проверять обе лестницы/этажи/проёмы и live match при3456×2160, штатном VSync, с запасом к8.33мс. Изменение света пока не разрешено и не выполнено.
