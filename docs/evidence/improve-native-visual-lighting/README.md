# Native visual lighting and controls

Согласованный scope: свет → материалы → AO → bloom → отражения, без новой геометрии/частиц. Пять общих сохраняемых переключателей и силы 0–100% в меню и личной паузе; AO 25%-шаг, остальные 5%. Defaults 50%, включены; выключение сохраняет силу и восстанавливает baseline. Lab: «Графика → Свет и эффекты».

Последний результат каждого из 111 уникальных affected tests — Passed (78 EditMode, 33 PlayMode). XML и сжатые логи в tests/; результаты прежних провалов сохранены и заменены точечными повторными проверками, без ослабления assertions/seeds/timeouts. Это не full suite.

23 PNG: до, каждый эффект отдельно, всё вместе для Combat Bowl, Industrial Tunnels и Lunar Laboratory, плюс верх/низ графического меню. Игровые PNG собирают четыре независимо отрендеренных viewport; это не физический экран. Проверены геометрия/collider count, обратимость, singleton resources, сохранение, миграция неизменяемых Lab snapshots/hashes, shared pause controls и frozen clock. Цвета participants сохранены.

Локальные тени сохранили прежний бюджет; URP сообщал понижение разрешения существующих дополнительных теней при capture. Shadow atlas не увеличивался. Постобработка/отражения требуют будущей проверки GPU/Player/устройств; FPS не измерялся. Один probe для всей карты — приближённое окружение, без актуализации при каждом движении/выстреле.

Player build, установщики, full tests, release/deploy не выполнены и не разрешены этой задачей. Визуальная приёмка человеком открыта. Ни technical tests, ни изображения её не заменяют.
