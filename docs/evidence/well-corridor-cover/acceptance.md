# Человеческая проверка
Исходная точка: main 48e1e1f4; implementation revision и hashes после QA перечислены в verification.json.

1. На каждом этаже «Колодца» есть одна складская группа из двух кейсов, один рабочий островок и один шкаф у стены. Это редкие зоны хранения/обслуживания; в проходах нет случайной мелочи.
2. Обойти каждый новый корпус с обычным управлением. Корпус блокирует игрока и выстрел; пути к прежним дверям/лестницам/лифтам/спавнам/предметам доступны.
3. Посмотреть на коридор в целом: остаётся ощущение простора, а типы предметов соответствуют лаборатории. Сравнить настоящие Editor PNG в views/ с согласованными макетами в concepts/; макеты не являются runtime evidence.
4. В Lab сохранён старый authoring revision 3 с точными hashes; новая совместимая копия использует revision 4 и прежние игровые настройки.

Editor автоматические проверки и снимки не заменяют игровую/человеческую/аппаратную приёмку. Player build/full suite/deploy не выполнялись и требуют отдельных команд.
