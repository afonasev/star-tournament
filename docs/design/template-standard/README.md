# Макеты приведения к стандарту

Требования: game-spec-templates `0c2d4562683252d54736f294dc1af463050eac17`, каталог 0.5.0.
Baseline игры: `973c28773518eebd64bbab4f43ed66821d5770d8`.

Открыть `index.html` для всех экранов. A сохраняет левую навигацию; B показывает альтернативные верхние вкладки. Другие экраны общие для обоих вариантов. Содержимое и значения иллюстративные, defaults/баланс этим не утверждаются. Это макеты, не снимки и не реализация Unity.

Рендер: `python3 docs/design/template-standard/mockups.py` (нужен `rsvg-convert`). Исходники SVG, PNG и генератор сохраняются вместе.

До изменений UI требуется решение пользователя о направлении и замечаниях. Для не представленных здесь экранов настроек, справки, ввода текста и модальных состояний сначала показать следующие макеты. Согласование этих изображений не является разрешением на иное оформление и не является runtime/device/human acceptance игры.
