# Совместимость контроллеров в Unity Player

Игра принимает устройство, которое установленный Unity Input System 1.20.0 распознал как семантический `Gamepad`. В setup и настройках видно его имя и статус. Физическое подключение к macOS или Windows само по себе не подтверждает такую раскладку. Ниже перечислены layout, присутствующие в используемом пакете, и режимы сторонних устройств; это матрица автоматической совместимости, а не результаты физической приёмки каждой модели.

| Семейство / модель | macOS | Windows | Основание и ограничение |
| --- | --- | --- | --- |
| Xbox One / Series; Xbox 360 с legacy-драйвером | Штатные macOS Xbox layout для распознанных One/Series и Xbox 360 с 360Controller на macOS ≤10.15 | Штатный XInput layout для 360/One/Series | Конкретная ревизия и USB/Bluetooth требуют физической проверки. |
| DualShock 3 / 4, DualSense, DualSense Edge | Штатные Sony HID layout | Штатные Sony HID layout | Проверяются базовые игровые действия; дополнительные функции контроллера вне scope. |
| Nintendo Switch Pro | Штатный Switch Pro HID layout | Штатный Switch Pro HID layout | Nintendo VID/PID `057e:2009`; режим подключения и ревизия требуют физической проверки. |
| Hori / PDP / PowerA Switch-совместимые | Перечисленные в `SwitchSupportHID` VID/PID | Те же HID layout при обнаружении | Только конкретные модели/идентификаторы из пакета; не все изделия бренда. |
| 8BitDo SN30 Pro | Отдельный проверенный HID layout для Bluetooth X-input firmware 9.0.3 | XInput при распознавании системой | Другие ревизии и режимы требуют физической проверки. |
| Другие 8BitDo, Logitech F310 и совместимые сторонние | Только если ОС и Unity выдают `Gamepad` с полной раскладкой | XInput-режим, если Unity выдаёт `Gamepad` | Для F310 DirectInput и произвольного HID нет безопасной общей раскладки; устройство показывается как неподдержанный `Joystick`. |

В интерфейсе generic `Joystick` виден, но недоступен для назначения: выберите XInput/совместимый режим контроллера либо потребуется отдельный профиль модели. Ручная калибровка и настройка неизвестных HID относятся к отдельной будущей работе. Проверка реальных устройств, reconnect, focus и split-screen остаётся открытой до физического теста; синтетические `InputDeviceDescription` не заменяют его.
