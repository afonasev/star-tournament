# Внешние инструменты

Прочитай этот файл перед подключением MCP, плагина или внешнего сервиса.

- Не подключай и не используй MCP, плагины или внешние сервисы «на всякий случай».
- Для кода, файлов, тестов, сборки, Git и локального плейтеста сначала используй локальные инструменты, OpenSpec-skills и in-app Browser.
- Внешний MCP допустим, только когда этого явно требует задача либо без него нельзя получить первичные данные. Перед подключением объясни цель и минимальный объём доступа.
- Не добавляй в репозиторий конфигурации MCP, секреты, токены или зависимости от удалённого сервиса без отдельного явного согласия пользователя.
