# Game QA

Прочитай этот файл перед player-visible, input, split-screen, network-play, audio или browser-QA задачей.

Для Unity набор автоматических проверок выбирается по `qa-scope.md`: UI-only change допускает `make check-ui` и tests затронутого экрана без полного bot-прогона. Для видимых изменений обязательны muted native Player playtest, screenshots изменённых состояний и Player build. Focus/cursor capture, четыре независимых устройства, reconnect и TV проверяются физически; automated input и четыре камеры не заменяют эту приёмку. Output Full HD–4K и минимум 60 FPS для четырёх игроков — целевой контракт, reference hardware/quality ещё открыты. Benchmark на текущем Mac маркируется diagnostic до согласования условий. Browser-правила ниже продолжают описывать historical browser runtime, а закрытый cancelled/superseded backlog не возобновляется ради Unity.

- Для каждого изменения, затрагивающего геймпад, клавиатуру/мышь, split-screen или сетевую игру, обязательна проверка в in-app Browser; сборка и автотесты сами по себе не доказывают играбельность.
- Для любого изменения, которое меняет видимый результат в игре — WebGL-сцену, модели, материалы, освещение, эффекты, камеры, HUD, меню, лабораторию или другой DOM/UI, — после проверки в in-app Browser приложи к итоговому сообщению актуальные скриншоты из dev-стенда изменённой ветки. Скриншоты обязательны для handoff и не заменяют browser playtest; если изменение затрагивает несколько состояний, экранов или viewport, покажи каждое изменённое состояние.
- Все локальные тесты и browser playtest проводи с выключенным звуковым выводом игры. Включать звук допустимо только на время проверки, которая непосредственно касается аудио; после такой проверки снова выключи его.
