# Context, models and budgets

No always-running coordinator. Model choice, minimum effort, delegation authorization and returned-evidence responsibility: [../model-routing.md](../model-routing.md). No global model pins or credential/approval changes. Batch only related small changes sharing context/checks; retain separate lifecycle records.

QA selection, reruns and test contracts: [../qa-scope.md](../qa-scope.md). After two unsuccessful attempts reassess approach/model/scope rather than loop. Use configured budgets when present; do not invent a token budget. Log usage externally reported by runtime with unknown fields null. Separate worker, review and coordination costs, cached and uncached input. Optimize accepted-result cost and rework, not just cheapest model per call.

Context, reads, visual handoff and replacement of a saturated session: [../context-efficiency.md](../context-efficiency.md). Process/chat waiting and concrete tool-call defaults: [../coordination.md](../coordination.md). Read each at first use; revisit only changed or missing ranges. Future runners retain the same transitions, locks and evidence contracts.
